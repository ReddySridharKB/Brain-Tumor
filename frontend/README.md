# NeuroAI Frontend

Futuristic AI-powered medical dashboard for Brain Tumor Detection & Monitoring System.

## Architecture

Built with Next.js 15 (App Router), Tailwind CSS v4, and Framer Motion. 
Features a cinematic, glassmorphic UI with dynamic hover lighting ("SpotlightCard" effect) and a floating navbar to replace traditional, generic hospital interfaces.

## Setup Instructions

1. **Install Dependencies**
   Navigate to the `frontend` folder:
   ```bash
   cd frontend
   npm install
   ```

2. **Run the Development Server**
   ```bash
   npm run dev
   ```

3. **Open in Browser**
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Key Components
- `SpotlightCard`: Used for dynamic hover lighting across dashboard and analysis cards.
- `FloatingNavbar`: Main navigation for pages.
- `Recharts`: Implemented for monitoring metrics and analytics over time.
- `Framer Motion`: Handled staggered reveals, route transitions, and UI hover effects.

## Theming
The UI respects the designated color palette (Deep Black, Matte Charcoal, Graphite Grey) with silver accents. No bright neon colors are used, prioritizing a premium AI healthcare aesthetic.
